# Website Galeri Foto

Aplikasi web galeri foto berbasis PHP dan MySQL dengan sistem login dan register.

## Fitur
- Registrasi, login, logout
- Tambah, lihat, edit, hapus foto

## Teknologi
PHP, MySQL, HTML, CSS, XAMPP

## Cara Instalasi
1. Salin folder ke `C:\xampp\htdocs\galeri`
2. Jalankan Apache dan MySQL di XAMPP
3. Buat database `db_galeri` di phpMyAdmin, lalu import `db_galeri.sql`
4. Buka `http://localhost/galeri/register.php`
